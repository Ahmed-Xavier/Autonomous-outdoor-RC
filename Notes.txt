# ROS 2 Environment

Always source before running ROS 2 commands:

source /opt/ros/jazzy/setup.bash

# micro-ROS

Start the micro-ROS agent on the Raspberry Pi:

ros2 run micro_ros_agent micro_ros_agent udp4 --port 8888 -v4
(verbose from 0 to 6 depends on the level of debugging)

The ESP32 currently connects to the agent over Wi-Fi.

## Current ESP32 Topics

Encoder:

ros2 topic echo /esp32/encoder

Check encoder publishing rate:

ros2 topic hz /esp32/encoder

Current target rate: approximately 20 Hz.

Motor command:

ros2 topic pub -r 10 /esp32/motor_cmd std_msgs/msg/Int16 "{data: 100}"

Stop motor:

ros2 topic pub --once /esp32/motor_cmd std_msgs/msg/Int16 "{data: 0}"

Servo command:

ros2 topic pub --once /esp32/servo_cmd std_msgs/msg/Int16 "{data: 50}"

Current servo calibration:

28 = maximum RIGHT
48 = CENTER
68 = maximum LEFT

# Map / Navigation

Start map server:

ros2 run nav2_map_server map_server --ros-args -p yaml_filename:=$HOME/map.yaml

Activate it:

ros2 run nav2_util lifecycle_bringup map_server

# Foxglove

Start the Foxglove bridge:

ros2 launch foxglove_bridge foxglove_bridge_launch.xml

Foxglove has been tested for map visualization, including a Google Earth screenshot as a development/test map source.

#vehicle control 

ros2 run vehicle_control vehicle_controller

#vehicle description

ros2 launch vehicle_bringup description.launch.py

# Hardware Pinout

## JGA25-370 motor + encoder cable

Yellow = Encoder A -> ESP32 GPIO 33
White = Encoder B -> ESP32 GPIO 32
Blue = Encoder VCC -> 5 V
Green = Encoder GND -> GND
Black = Motor negative -> GND / motor supply negative
Red = Motor positive -> +12 V

## L298N motor driver

IN1 -> ESP32 GPIO 26
IN2 -> ESP32 GPIO 27
ENA/PWM -> ESP32 GPIO 25

## Steering servo

Signal -> ESP32 GPIO 14
