# Hardware Documentation

## Main Computer

- Raspberry Pi 4 Model B
- Ubuntu 24.04
- ROS 2 Jazzy

## Low-Level Controller

- ESP32

Responsibilities:
- Motor control
- Wheel encoder reading
- BNO055 IMU reading
- Steering servo control

## Sensors

- BNO055 IMU
- GPS / GNSS
- LiDAR
- Camera
- Wheel encoders

## Actuators

- Rear propulsion motor(s)
- Front steering servo

## Vehicle Platform

Initial platform: RC car

Future platform: Shell Eco-marathon Prototype concept vehicle
